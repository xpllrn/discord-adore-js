# Discord Components V2 Migration Guide

## Overview

Discord's Components V2 (Display Components) is a modern alternative to embeds that provides more flexibility and better styling options. This guide will help you migrate from the old embed system to the new display components.

## Key Differences

### Old System (Embeds)
- Uses `EmbedBuilder`
- Limited layout options
- Separate components array for buttons
- No `MessageFlags.IsComponentsV2` flag

### New System (Display Components)
- Uses `ContainerBuilder`, `SectionBuilder`, `TextDisplayBuilder`, etc.
- Flexible layout with containers, sections, and separators
- Components integrated within containers
- **Requires** `MessageFlags.IsComponentsV2` flag
- **Cannot** use `content`, `embeds`, `poll`, or `stickers` fields

## Important Rules

1. **You MUST pass `MessageFlags.IsComponentsV2`** when sending messages with display components
2. **You CANNOT use** `content`, `embeds`, `poll`, or `stickers` when using Components V2
3. Messages can have up to **40 total components** (nested components count!)
4. Total text across all components cannot exceed **4000 characters**
5. All attached files must be explicitly referenced in a component

## Required Imports

```javascript
const { 
  ContainerBuilder, 
  SectionBuilder, 
  TextDisplayBuilder,
  SeparatorBuilder,
  ThumbnailBuilder,
  MediaGalleryBuilder,
  FileBuilder,
  ButtonBuilder,
  ButtonStyle,
  MessageFlags 
} = require('discord.js');
```

## Component Types

### 1. ContainerBuilder
The main wrapper component - similar to an embed but more flexible.

```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)  // Optional left accent color
  .setSpoiler(false);         // Optional spoiler blur
```

**Methods:**
- `.setAccentColor(color)` - Set left border color (hex or RGB)
- `.setSpoiler(boolean)` - Blur all content inside
- `.addTextDisplayComponents(...)` - Add text components
- `.addSectionComponents(...)` - Add section components
- `.addSeparatorComponents(...)` - Add separator components
- `.addActionRowComponents(...)` - Add button rows
- `.addMediaGalleryComponents(...)` - Add media galleries
- `.addFileComponents(...)` - Add file components

### 2. TextDisplayBuilder
Displays markdown-formatted text - replaces embed `title`, `description`, and `fields`.

```javascript
container.addTextDisplayComponents(
  (text) => text.setContent('# This is a heading'),
  (text) => text.setContent('**Bold text** and *italic text*'),
  (text) => text.setContent('Regular text with [links](https://discord.com)')
);
```

**Supports all Discord markdown:**
- Headers: `# H1`, `## H2`, `### H3`
- Bold: `**text**`
- Italic: `*text*`
- Code: `` `code` `` or ` ```code block``` `
- Links: `[text](url)`
- Mentions: `<@userId>`, `<@&roleId>`, `<#channelId>`
- Timestamps: `<t:timestamp:format>`

### 3. SectionBuilder
Combines 1-3 text displays with an accessory (button or thumbnail).

```javascript
container.addSectionComponents((section) =>
  section
    .addTextDisplayComponents(
      (text) => text.setContent('**Title**'),
      (text) => text.setContent('Description text'),
      (text) => text.setContent('Additional info')
    )
    .setThumbnailAccessory((thumbnail) =>
      thumbnail
        .setURL('https://example.com/image.png')
        .setDescription('Alt text for accessibility')
        .setSpoiler(false)
    )
);
```

**Or with a button accessory:**
```javascript
container.addSectionComponents((section) =>
  section
    .addTextDisplayComponents(
      (text) => text.setContent('Click the button!')
    )
    .setButtonAccessory((button) =>
      button
        .setCustomId('myButton')
        .setLabel('Click Me')
        .setStyle(ButtonStyle.Primary)
    )
);
```

### 4. SeparatorBuilder
Adds vertical spacing and optional divider line between components.

```javascript
const { SeparatorSpacingSize } = require('discord.js');

container.addSeparatorComponents((separator) => 
  separator
    .setDivider(true)  // Show divider line (default: true)
    .setSpacing(SeparatorSpacingSize.Large)  // Small or Large
);

// Simple separator with defaults
container.addSeparatorComponents((separator) => separator);
```

### 5. ThumbnailBuilder
Display images (similar to embed thumbnail) - used as accessory in sections.

```javascript
.setThumbnailAccessory((thumbnail) =>
  thumbnail
    .setURL('attachment://image.png')  // or external URL
    .setDescription('Alt text')
    .setSpoiler(false)
)
```

### 6. MediaGalleryBuilder
Display a grid of up to 10 images.

```javascript
const { MediaGalleryItemBuilder } = require('discord.js');

container.addMediaGalleryComponents((gallery) =>
  gallery.addItems(
    (item) => item
      .setURL('https://example.com/image1.png')
      .setDescription('Image 1 alt text')
      .setSpoiler(false),
    (item) => item
      .setURL('attachment://image2.png')
      .setDescription('Image 2 alt text')
  )
);
```

### 7. FileBuilder
Display uploaded files within the message body.

```javascript
const { AttachmentBuilder } = require('discord.js');

const file = new AttachmentBuilder('../assets/document.pdf');

container.addFileComponents((fileComponent) =>
  fileComponent
    .setURL('attachment://document.pdf')
    .setSpoiler(false)
);

// Send with files array
await channel.send({
  components: [container],
  files: [file],
  flags: MessageFlags.IsComponentsV2
});
```

### 8. Buttons in Containers
Add buttons using ActionRow within containers.

```javascript
const { ActionRowBuilder } = require('discord.js');

container.addActionRowComponents((actionRow) =>
  actionRow.setComponents(
    new ButtonBuilder()
      .setCustomId('button1')
      .setLabel('Primary')
      .setStyle(ButtonStyle.Primary),
    new ButtonBuilder()
      .setStyle(ButtonStyle.Link)
      .setLabel('Link')
      .setURL('https://discord.com')
  )
);
```

## Migration Examples

### Example 1: Simple Embed → Container

**Before (Embed):**
```javascript
const embed = new EmbedBuilder()
  .setTitle('Hello World')
  .setDescription('This is a description')
  .setColor(0x0099ff);

await channel.send({ embeds: [embed] });
```

**After (Components V2):**
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents(
    (text) => text.setContent('# Hello World'),
    (text) => text.setContent('This is a description')
  );

await channel.send({
  components: [container],
  flags: MessageFlags.IsComponentsV2
});
```

### Example 2: Embed with Fields → Container with Sections

**Before (Embed):**
```javascript
const embed = new EmbedBuilder()
  .setTitle('User Info')
  .setColor(0x0099ff)
  .addFields(
    { name: 'Username', value: 'JohnDoe', inline: true },
    { name: 'ID', value: '123456789', inline: true },
    { name: 'Joined', value: '<t:1234567890:R>', inline: false }
  );

await channel.send({ embeds: [embed] });
```

**After (Components V2):**
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents((text) => text.setContent('# User Info'))
  .addSeparatorComponents((separator) => separator)
  .addTextDisplayComponents(
    (text) => text.setContent('**Username:** JohnDoe • **ID:** 123456789')
  )
  .addSeparatorComponents((separator) => separator)
  .addTextDisplayComponents(
    (text) => text.setContent('**Joined:** <t:1234567890:R>')
  );

await channel.send({
  components: [container],
  flags: MessageFlags.IsComponentsV2
});
```

### Example 3: Embed with Thumbnail → Section with Thumbnail

**Before (Embed):**
```javascript
const embed = new EmbedBuilder()
  .setTitle('Server Info')
  .setDescription('Welcome to our server!')
  .setThumbnail('https://example.com/icon.png')
  .setColor(0x0099ff);

await channel.send({ embeds: [embed] });
```

**After (Components V2):**
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addSectionComponents((section) =>
    section
      .addTextDisplayComponents(
        (text) => text.setContent('# Server Info'),
        (text) => text.setContent('Welcome to our server!')
      )
      .setThumbnailAccessory((thumbnail) =>
        thumbnail
          .setURL('https://example.com/icon.png')
          .setDescription('Server icon')
      )
  );

await channel.send({
  components: [container],
  flags: MessageFlags.IsComponentsV2
});
```

### Example 4: Embed with Buttons → Container with Buttons

**Before (Embed + Components):**
```javascript
const embed = new EmbedBuilder()
  .setTitle('Choose an option')
  .setColor(0x0099ff);

const row = new ActionRowBuilder()
  .addComponents(
    new ButtonBuilder()
      .setCustomId('option1')
      .setLabel('Option 1')
      .setStyle(ButtonStyle.Primary),
    new ButtonBuilder()
      .setCustomId('option2')
      .setLabel('Option 2')
      .setStyle(ButtonStyle.Secondary)
  );

await channel.send({
  embeds: [embed],
  components: [row]
});
```

**After (Components V2):**
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents(
    (text) => text.setContent('# Choose an option')
  )
  .addActionRowComponents((actionRow) =>
    actionRow.setComponents(
      new ButtonBuilder()
        .setCustomId('option1')
        .setLabel('Option 1')
        .setStyle(ButtonStyle.Primary),
      new ButtonBuilder()
        .setCustomId('option2')
        .setLabel('Option 2')
        .setStyle(ButtonStyle.Secondary)
    )
  );

await channel.send({
  components: [container],
  flags: MessageFlags.IsComponentsV2
});
```

### Example 5: Complex Embed → Full Container

**Before (Embed):**
```javascript
const embed = new EmbedBuilder()
  .setTitle('Server Statistics')
  .setDescription('Current server stats')
  .setColor(0x0099ff)
  .setThumbnail(guild.iconURL())
  .addFields(
    { name: 'Members', value: `${guild.memberCount}`, inline: true },
    { name: 'Channels', value: `${guild.channels.cache.size}`, inline: true },
    { name: 'Roles', value: `${guild.roles.cache.size}`, inline: true }
  )
  .setFooter({ text: `Server ID: ${guild.id}` })
  .setTimestamp();

await channel.send({ embeds: [embed] });
```

**After (Components V2):**
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff);

// Header with thumbnail
container.addSectionComponents((section) =>
  section
    .addTextDisplayComponents(
      (text) => text.setContent('# Server Statistics'),
      (text) => text.setContent('Current server stats')
    )
    .setThumbnailAccessory((thumbnail) =>
      thumbnail
        .setURL(guild.iconURL())
        .setDescription('Server icon')
    )
);

// Stats
container.addSeparatorComponents((separator) => separator);
container.addTextDisplayComponents(
  (text) => text.setContent(`**Members:** ${guild.memberCount} • **Channels:** ${guild.channels.cache.size} • **Roles:** ${guild.roles.cache.size}`)
);

// Footer
container.addSeparatorComponents((separator) => separator);
container.addTextDisplayComponents(
  (text) => text.setContent(`*Server ID: ${guild.id} • <t:${Math.floor(Date.now() / 1000)}:R>*`)
);

await channel.send({
  components: [container],
  flags: MessageFlags.IsComponentsV2
});
```

## Common Patterns

### Pattern 1: Title + Description + Fields
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents(
    (text) => text.setContent('# Title'),
    (text) => text.setContent('Description text')
  )
  .addSeparatorComponents((separator) => separator)
  .addTextDisplayComponents(
    (text) => text.setContent('**Field 1:** Value 1'),
    (text) => text.setContent('**Field 2:** Value 2')
  );
```

### Pattern 2: Multiple Sections with Separators
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff);

// Section 1
container.addTextDisplayComponents(
  (text) => text.setContent('**Section 1**'),
  (text) => text.setContent('Content for section 1')
);

// Separator
container.addSeparatorComponents((separator) => separator);

// Section 2
container.addTextDisplayComponents(
  (text) => text.setContent('**Section 2**'),
  (text) => text.setContent('Content for section 2')
);
```

### Pattern 3: Image Gallery
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents(
    (text) => text.setContent('# Image Gallery')
  )
  .addMediaGalleryComponents((gallery) =>
    gallery.addItems(
      (item) => item.setURL('https://example.com/1.png').setDescription('Image 1'),
      (item) => item.setURL('https://example.com/2.png').setDescription('Image 2'),
      (item) => item.setURL('https://example.com/3.png').setDescription('Image 3')
    )
  );
```

### Pattern 4: Conditional Content
```javascript
const container = new ContainerBuilder()
  .setAccentColor(0x0099ff)
  .addTextDisplayComponents(
    (text) => text.setContent('# User Profile')
  );

// Conditionally add thumbnail if avatar exists
if (user.avatarURL()) {
  container.addSectionComponents((section) =>
    section
      .addTextDisplayComponents(
        (text) => text.setContent(`**${user.username}**`)
      )
      .setThumbnailAccessory((thumbnail) =>
        thumbnail.setURL(user.avatarURL()).setDescription('User avatar')
      )
  );
} else {
  container.addTextDisplayComponents(
    (text) => text.setContent(`**${user.username}**`)
  );
}
```

## Troubleshooting

### Error: "Invalid Form Body"
- Make sure you're passing `MessageFlags.IsComponentsV2`
- Ensure you're not sending `content`, `embeds`, `poll`, or `stickers`
- Check that all components are properly built

### Error: "Too many components"
- Maximum 40 components total (nested components count)
- Reduce the number of text displays, sections, or separators

### Error: "Text too long"
- Maximum 4000 characters across all text components
- Split content into multiple messages if needed

### Buttons not showing
- Make sure buttons are wrapped in `addActionRowComponents`
- Check that button builders are properly configured
- Verify you're using `ButtonBuilder` not raw objects

### Images not displaying
- Ensure files are in the `files` array
- Use `attachment://filename` for local files
- Use full URLs for external images
- All attachments must be referenced in a component

## Best Practices

1. **Use separators** between logical sections for better readability
2. **Keep text concise** - display components work best with shorter content
3. **Use markdown** for emphasis (`**bold**`, `*italic*`)
4. **Add alt text** to all images for accessibility
5. **Group related info** in sections with thumbnails or buttons
6. **Test on mobile** - display components are optimized for mobile viewing
7. **Use accent colors** sparingly - they should enhance, not distract
8. **Limit nesting** - keep component structure simple when possible

## Migration Checklist

- [ ] Replace `EmbedBuilder` with `ContainerBuilder`
- [ ] Convert `setTitle()` to `addTextDisplayComponents()` with `# Title`
- [ ] Convert `setDescription()` to `addTextDisplayComponents()`
- [ ] Convert `addFields()` to `addTextDisplayComponents()` or `addSectionComponents()`
- [ ] Convert `setThumbnail()` to `setThumbnailAccessory()` in a section
- [ ] Convert `setColor()` to `setAccentColor()`
- [ ] Add `addSeparatorComponents()` between sections
- [ ] Move buttons into `addActionRowComponents()` within container
- [ ] Add `MessageFlags.IsComponentsV2` to send options
- [ ] Remove `embeds` array from send options
- [ ] Test the message appearance
